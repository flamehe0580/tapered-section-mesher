# tapered-section-mesher
A Python tool for automatic 2D cross-section mesh generation of tapered beams with invariant topology.
This repository provides an automated mesh deformation algorithm for generating 2D cross-sectional meshes of tapered beams. It maintains a fixed topological connectivity while smoothly morphing the nodal coordinates along the longitudinal axis, serving as a pre-processor for the 2D+1D finite element analysis of arbitrary cross-section beams.
